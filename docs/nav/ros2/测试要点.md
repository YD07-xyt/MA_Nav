## 无法验证的部分

【待确认】以下必须有实机或仿真验证才能判定（当前是单线程调度，多线程相关风险只在该前提被改变时才成立）：

1. 三个互斥回调组是否真的覆盖了所有跨组共享状态。
2. 20 s 失败判定的实际体感是否合理。
3. 折叠机构对折叠指令的响应时间与事件提前量是否匹配。
4. 全量可视化开启时对控制节拍的影响。
5. 外部点云/里程计发布者的 QoS 是否与订阅端匹配。
