场景与环境客观描述文档
一、 测试场地物理概况
该测试场地是一个仿公路/越野环境，包含平坦路面、斜坡（起伏路段）、隧道/限高杆结构以及不同高度的台阶。根据工程图纸（带尺寸标注）及 3D 渲染图，场地具有以下具体特征：

限高杆/门洞结构：

场地中设有多处类似门框或限高杆的跨越结构。横梁下方有净空高度（通常在 200mm-300mm 左右），允许低矮车辆通过。

关键地形特征：部分限高杆并非架设在绝对平整的地面上，而是横跨在有坡度的起伏路段上，或者横梁的一端靠近高地/高台。支撑横梁的立柱直接连接地面。

台阶与高台：

场地内存在高度突变的高台或台阶，高差通常在 15cm 以上。机器人无法直接攀爬通过。

斜坡与起伏路面：

存在连续的坡度路面，坡度较缓，地面高度（Z轴）会随着水平位移（X/Y轴）逐渐变化。

长条形矮墙/侧边障碍：

场地边缘或道路旁存在细长的垂直墙面，以及高度不一的隔离带。

二、 机器人本体情况
机器人为一台小型四轮/履带底盘（3D渲染图中显示为橙色微型车体）。(仿真)

现实:全向圆形

通过性约束：底盘低或车体高度有限，无法攀爬较高的垂直台阶（>5cm），但具备从限高杆下方钻过的能力（只要下方垂直间隙 > 26cm 左右）。

三、 3D 点云与 2D 感知地图的实际表现（现象描述）
在当前的感知建图过程中，由于雷达特性及地形复杂性，出现了以下客观现象：

限高杆提取异常（3D点云到2D栅格的断裂）：

在 3D 点云视图（RViz中的彩色高度图）中，限高杆的横梁点云清晰可见。

在 2D 占据栅格（白色投影图）中，位于平坦地面的限高杆前半段，能够被成功过滤（不生成2D障碍物，允许通行）。

但限高杆靠近高地/斜坡的后半段，未能被过滤，在 2D 栅格图中被错误地生成了白色障碍物。这是因为该段横梁不仅存在垂直下方的间隙，其与旁边高地的地面高差（梯度）也达到了陡峭的阈值，导致算法将其判定为“从地面升起的一堵墙”。

台阶与坡道旁的 2D 障碍物不完整（漏检/收缩）：

对于实际存在的台阶边缘和长条形墙壁，在 2D 栅格图（白色区块）中，障碍物的边界出现了不连续、断裂或形态收缩的情况。

台阶的锐利边缘在滤波和稀疏点云的影响下，未能完整闭合，导致 2D 栅格上的障碍轮廓无法完全堵死通道，表现出“漏检”现象。

四、 归纳总结（给接收方 AI 的背景信息）
当前输入的地形分析算法，核心逻辑依赖网格内的最低点（地面）和最高点（障碍物）、邻域高度梯度（识别陡峭边缘），以及垂直方向的间隙分析（判断能否钻过）。

实际遇到的困难是：当“悬空结构（限高杆）”与“地面高度突变（斜坡/高地）”在同一个网格或相邻网格交汇时，算法产生了误判；同时由于点云稀疏或滤波，导致垂直边缘的识别不完整。
