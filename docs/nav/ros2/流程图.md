## 规划流程（plan_omni）

```mermaid
stateDiagram-v2
    [*] --> 无目标
    无目标 --> 等待: goal 或位姿缺失
    无目标 --> 到达: 距目标小于到达半径
    到达 --> 等待: 清空目标后返回
    无目标 --> 调用重规划: 目标与位姿齐全
    调用重规划 --> 规划失败: 返回错误
    调用重规划 --> 非成功态: 状态不是成功
    调用重规划 --> 成功: 状态为成功
    规划失败 --> 超时判失败: 距上次计时超过 20 秒
    非成功态 --> 超时判失败: 距上次计时超过 20 秒
    非成功态 --> 运行中: 未超时
    成功 --> 新轨迹处理: 是新轨迹
    成功 --> 发布反馈: 不是新轨迹
    新轨迹处理 --> 发布反馈
```

| 状态/迁移 | 对应符号 | 锚点 |
|---|---|---|
| 缺目标/位姿 | 直接返回 | `src/ros2/src/ros2_node.cpp:249-256` |
| 到达 | 置成功、发布反馈、清空目标 | `src/ros2/src/ros2_node.cpp:260-269` |
| 20 秒判失败 | 首次失败开始计时 | `src/ros2/src/ros2_node.cpp:271-279` |
| 未超时 | 置运行中 | `src/ros2/src/ros2_node.cpp:290-293` |
| 新轨迹处理 | 更新 MPC 目标、重算折叠事件、定位跟踪游标 | `src/ros2/src/ros2_node.cpp:308-344` |

## 控制流程（controller_callback）

```mermaid
sequenceDiagram
    participant C as controller_callback
    participant T as MaSplineTrajectoryInterface
    participant M as Mpc
    participant F as fold_pub
    participant V as cmd_vel_pub
    C->>T: valid() + update_track_time(pos, t_track)
    C->>C: 组装 4 状态（上帧指令优先，否则里程计并限幅）
    C->>M: solve(x0, t_now, ...)
    M-->>C: 控制量 + 预测序列（失败则本帧不下发）
    C->>F: 按事件时间发布折叠/展开指令
    C->>C: 世界系 → 车体系 + ±20/NaN 保护
    C->>V: 发布 Twist
```
