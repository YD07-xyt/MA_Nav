## 数据流

1. 输入：调用方依次注入地图、参数、速度，再调用规划
   （`src/planner/replan/src/fsm_replanner.cpp:60`、`src/planner/replan/src/fsm_replanner.cpp:72`、`src/planner/replan/src/fsm_replanner.cpp:74`）。
2. 搜索：按 `use_jps_` 二选一，得到 `raw_path`
   （`src/planner/path_planning/src/path_planning.cpp:41-42`）；空则直接返回 `std::nullopt`
   （`src/planner/path_planning/src/path_planning.cpp:44-46`）。
3. 剪枝：`optimize_path` 用 Bresenham 直线碰撞检查决定能否跳过中间点
   （`src/planner/path_planning/src/post_processing.cpp:19-43`）。
4. 采样：`sample_path_states` 生成 5D 状态 (x, y, θ, Δθ, Δs)
   （`src/planner/path_planning/src/post_processing.cpp:89-111`）。
5. 时间分配：`assign_trajectory_timing` 依次做高密度采样 → 等效距离（含转弯惩罚）
   → 隧道前折叠降速 → 前向/后向速度传播 → 积分时间 → 均匀分段重采样
   （`src/planner/path_planning/src/post_processing.cpp:158-305`）。
6. 补充信息：`fill_additional_trajectory_info` 写入起终点 XYTheta、占用序列、截断标志
   （`src/planner/path_planning/src/post_processing.cpp:308-339`）。
7. 输出：`timed_trajectory` 为空或无有效时间则丢弃本次结果
   （`src/planner/path_planning/src/path_planning.cpp:58-61`），否则返回轨迹对象。

【事实】第 5 步的速度上限初值是「全程 max_vel，仅首尾点取 start_vel / end_vel」
（`src/planner/path_planning/src/post_processing.cpp:210-212`），
折叠降速只在隧道入口之前叠加（`src/planner/path_planning/src/post_processing.cpp:417-422`）。

## 关键设计决策

| 决策 | 证据锚点 | 是否代码明示 |
|---|---|---|
| 用 Pimpl 把实现细节关在 .cpp 内 | `src/planner/path_planning/src/path_planning.cpp:72` | 是（头文件注释说明了 unique_ptr 的实例化位置） |

| JPS 用扁平数组 + 代际计数，避免每次搜索 O(N) 清零 | `src/planner/path_planning/src/search/jps.cpp:39-43` | 是（注释解释不能重置代际） |
| JPS 起点被占用时吸附到最近可通行栅格 | `src/planner/path_planning/src/search/jps.cpp:221-224` | 是（注释说明与 A* 行为对齐） |
| 隧道内不做降速，只在隧道**入口前**降速 | `src/planner/path_planning/src/post_processing.cpp:405-406` | 是（注释给出准备距离公式） |
| 转向越大等效距离越长，从而时间更充裕 | `src/planner/path_planning/src/post_processing.cpp:187-188` | 是（注释「线性距离 + 转弯惩罚 × |Δθ|」） |

【推断】决策 7 的代价：`set_map` 以 `const&` 入参但赋值给值成员
（`src/planner/path_planning/include/path_planning/search/astar.h:61`、

而 replan 每次规划前都调用一次
（`src/planner/path_planning/src/path_planning.cpp:7-11`），
因此 JPS 的数组尺寸检查与 `blocked_cache_` 重建是**每次规划**都会发生的
（`src/planner/path_planning/src/search/jps.cpp:30-38`）。

## 线程与并发

【事实】本模块源码不含任何互斥量、原子量或线程/定时器设施：
`src/planner/path_planning/include/path_planning/search/jps.h:4-7` 的 include 列表
只有 STL 容器与 Eigen，`PathPlanning` 也无回调注册接口
（`src/planner/path_planning/include/path_planning/path_planning.hpp:2-5`）。

【推断】对象**非线程安全**：`JPS` 在搜索过程中读写自身可变状态
（`src/planner/path_planning/include/path_planning/search/jps.h:59-71`），
`jps_search` 也不是 const 成员函数
（`src/planner/path_planning/include/path_planning/search/jps.h:45`）。
当前调用方 replan 是单线程顺序调用
（`src/planner/replan/src/fsm_replanner.cpp:74`），
若日后并发规划，必须每个线程独立实例。
