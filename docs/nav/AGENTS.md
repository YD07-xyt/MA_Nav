# 项目 Agent 行为准则(编写文档)

本文件是本仓库中 编写文档时 AI Agent、Codex、Claude、dsh 、superpower skill、多 agent 工作流的统一行为规范。  
所有代码修改、审计、重构、调参、文档化任务都必须优先阅读并遵守本文件。

本仓库任何修改都必须以“保持可复现、最小改动、可审计”为第一原则。

## 安全与隐私

1. 不允许写入涉密及敏感材料的信息

2. 在将任何材料输入 AI 之前，必须进行严格的脱敏处理，涉密及敏感材料（如账号、密钥、手机号、身份证号、未公开的客户数据）一律不得进入工具处理范围。
AI 生成的内容也需仔细检查，确保没有泄露隐私或涉密信息

## 质量与准确性

在缺乏依据时不允许编造数据、案例或技术指标

1. 限定知识来源：AI 仅基于用户提供的、经过确认的资料进行生成，知识库缺口必须显式标注，绝不允许凭空填充。

2. 强制要求溯源：AI 将“原文事实、合理推断、需要确认”分开呈现，并在事实后标记来源文件，方便用户回溯核查。

3. 人工审核闭环：AI 生成的草稿必须经过你的审核，确认无误后才能进入下一环节。绝不允许跳过审核步骤
