## 单阶段优化内部时序（L-BFGS ↔ 求值规格）

```mermaid
sequenceDiagram
    participant S as optimize_2d_stage / optimize_3d_stage
    participant O as SplineOptimizer
    participant C as cost 回调
    participant L as lbfgs
    S->>O: setConfig + prepareContext
    S->>O: generateInitialGuess（首阶段）
    S->>C: 组装 TimeCost / RobotIntegralCost
    S->>O: makeEvaluateSpec
    S->>L: lbfgs_optimize(cost_callback_2d/3d)
    L->>C: 回调取代价与梯度
    C->>O: evaluatePrepared
    O-->>C: cost + gradient
    L-->>S: 返回码 + 最终代价
```
