## 无法验证的部分

【待确认】以下必须有实机、仿真或离线数值实验才能判定：

1. 当前权重（Q 30/30/1/1、QN 40/40/2/2、R 0.05、Rd 0.05）的实际跟踪表现。
2. 求解耗时是否满足控制周期（每帧一次 QP，N=20 时 124 变量 / 164 约束）。
3. 是否需要跨帧控制平滑（即 `u_prev` 是否本应参与惩罚）。
4. yaw 控制是否计划在本模块闭环。
