## 附：代码注释规范（原文保留）

参考各个类、函数、成员变量的标准：

1. 注释写在头文件声明处，接口使用者主要看头文件。
2. @param 顺序与函数参数顺序一致。
3. 参数说明写清楚：范围、单位、是否可为空、所有权、生命周期。
4. 有异常必须写 @throws。
5. void 函数不写 @return。
6. 成员变量用 ///< 写在后面。
7. 不要写“设置 x”这种复述代码的注释，要写约束、意图、副作用。
8. 修改代码时同步修改注释。
